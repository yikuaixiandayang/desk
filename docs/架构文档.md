# 📐 银月桌宠架构文档

> **一句话心法**：Electron 三进程架构（主进程管逻辑+数据+IPC，渲染进程管画面+交互，预加载桥安全连接），用户输入先走本地技能路由（秒回零token），匹配不到再调 Hermes GLM API，长期记忆每12轮自动总结注入上下文——越用越懂你。

## 一、整体架构图

![架构图](./architecture.mmd)

### Electron 三进程模型

| 进程 | 职责 | 技术 |
|------|------|------|
| **主进程** | 窗口管理、托盘、全局快捷键、18个服务模块、IPC、数据持久化 | Node.js + electron-store + SQLite |
| **渲染进程** | Canvas 精灵图渲染、自主走动、情绪行为、对话UI、TTS/ASR、特效 | Canvas 2D + WebAudio + Vosk |
| **预加载桥** | contextBridge 安全暴露 IPC 接口（渲染进程不能直接 require Node） | Electron preload |

### 技术栈

| 层 | 技术 | 版本 |
|----|------|------|
| 框架 | Electron + electron-vite | Electron 39 |
| 语言 | TypeScript（全量类型） | TS 5.6 |
| 持久化 | electron-store（JSON）+ node:sqlite | - |
| AI | Hermes Agent API（OpenAI 兼容） | GLM-5.2 |
| 语音 | Edge TTS（神经语音）+ Vosk（离线ASR） | - |
| 测试 | Vitest | v3 |
| 打包 | electron-builder（Windows） | v26 |

## 二、数据交互流程

![数据流](./data-flow.mmd)

### 6 个核心场景

| # | 场景 | 路径 | 数据流 |
|---|------|------|--------|
| ① | 对话 | 渲染→IPC→chat-router→本地技能 or GLM | 意图解析→本地秒回 or GLM对话→存历史→气泡+TTS |
| ② | 记忆总结 | 每12轮自动触发 | 取近期对话→GLM总结→≤20条要点→electron-store+明文副本 |
| ③ | 定时提醒 | 用户输入→scheduler→到点播报 | 解析时间→存timers→每10秒检查→气泡+TTS→确认/生气 |
| ④ | 番茄钟 | 用户输入→pomodoro→25分钟专注 | 启动→安静不打扰→完成→三选择→统计 |
| ⑤ | 性格养成 | 每次互动→nurture→四维累加 | 话唠/粘人/学霸/探险→取最高→性格标签→注入prompt |
| ⑥ | 启动恢复 | 主进程读electron-store→补发错过提醒 | 恢复全部状态→检查timers→补发→渲染恢复 |

## 三、数据存储 ER 图

![数据库](./database-schema.mmd)

### 双库设计

| 存储引擎 | 文件 | 存什么 | 特点 |
|----------|------|--------|------|
| **electron-store** | `config.json` | 情绪/历史/好感/性格/番茄钟/待办/记忆/日记/成就/配置 | JSON 键值，全量状态 |
| **SQLite** | `pet-stats.db` | 提醒送达记录 + 成就解锁记录 | WAL 模式，统计口径 |
| **明文副本** | `记忆.json` + `记忆.md` | 长期记忆要点 | 用户可读可备份可导出 |

### electron-store 核心字段

| 字段 | 类型 | 内容 |
|------|------|------|
| `emotion` | object | 当前情绪 + 临时情绪到期时间 |
| `history` | array | 对话历史（user/assistant 消息列表） |
| `nurture` | object | 好感度(0-100) + 经验值 + 等级 + 今日统计 |
| `personality` | object | 四维累计（话唠/粘人/学霸/探险） |
| `memory` | object | 记忆要点列表 + 更新时间 + 总结次数 |
| `timers` | array | 定时提醒列表 |
| `todos` | array | 待办清单 |
| `pomodoro` | object | 番茄钟状态 |
| `diary` | array | 银月日记（保留90天） |
| `achievements` | array | 成就解锁记录 |
| `appConfig` | object | API 地址/Key/模型/记忆目录 |

## 七、AI 对话路由

### 路由优先级（chat-router.ts）

```
用户输入
  │
  ├─ ① 待回答的谜语？ → 检查答案 → 本地秒回
  ├─ ② 本地技能匹配？
  │     ├─ 提醒（"30分钟后..."）→ 本地解析时间 → scheduler
  │     ├─ 待办（"记一下/完成了..."）→ 本地增删查
  │     ├─ 番茄钟（"开个番茄钟..."）→ 本地启动
  │     ├─ 环境音（"放点雨声..."）→ WebAudio 合成
  │     ├─ 天气（"上海天气..."）→ Open-Meteo API
  │     ├─ 今日报告（"今日总结"）→ 本地统计
  │     ├─ 谜语（"出个谜语"）→ 内置32条
  │     ├─ 写日记（"写日记"）→ GLM 生成
  │     ├─ 本地秒回（"几点了/讲个笑话/你能做什么"）→ 零token
  │     └─ 以上都不匹配 ↓
  ├─ ③ GLM 对话 → buildSystemPrompt（情绪+好感+性格+记忆）→ Hermes API
  └─ ④ Hermes 不可用 → 离线预设回复（带【离线回复】标记）
```

### 本地技能 vs GLM 对比

| 特性 | 本地技能 | GLM 对话 |
|------|----------|----------|
| 延迟 | 零延迟 | 1-3 秒 |
| Token | 零消耗 | 每次消耗 |
| 可靠性 | 100%（离线可用） | 依赖网络 |
| 智能 | 固定规则 | 大模型理解 |

## 八、长期记忆机制

### 记忆生命周期

```
对话进行中
  │
  ├─ 每条助手回复 → 计数 +1
  ├─ 每 12 条 → 触发记忆总结
  │     ├─ 取近期对话历史
  │     ├─ GLM 提炼为 ≤20 条要点（JSON）
  │     ├─ 写入 electron-store（memory 字段）
  │     └─ 写入明文副本（记忆.json + 记忆.md）
  │
  └─ 下次对话 → 记忆要点注入 system prompt
      → GLM "记住" 了用户称呼/偏好/日程/习惯
```

### 双份持久化

| 存储 | 位置 | 格式 | 用途 |
|------|------|------|------|
| electron-store | `%APPDATA%/desktop-pet-yinyue/config.json` | JSON | 程序读取 |
| 明文副本 | 用户指定目录（默认 `~/银月记忆/`） | JSON + Markdown | 人工阅读/备份/导出导入 |

## 九、情绪与性格系统

### 12 种情绪

| 情绪 | 触发 | 行为表现 |
|------|------|----------|
| 😊 开心 | 好感≥75/被摸头 | 蹦跳大、头顶星光、语速轻快 |
| 😠 生气 | 接口异常/提醒不理 | 蹲原地不走、怒气符号、说话变冲 |
| 🥺 撒娇 | 好感高想被关注 | 冒爱心、粘人台词、音调+15% |
| 😢 委屈 | 好感<20/长期冷落 | 趴下、掉眼泪、轻声细语 |
| 😲 惊讶 | 提醒突然弹出 | 定格+放大弹跳 |
| 😴 困倦 | 23点后空闲 | 打瞌睡、冒Zzz、劝睡 |
| 🤩 兴奋 | 10分钟互动≥3次 | 小碎步跑、弹跳翻倍、语速+18% |
| 😑 无聊 | 空闲30分钟+ | 有气无力、主动搭话 |
| 🙂 平静 | 默认 | 正常待机走动 |
| 🤔 好奇 | v0.6新增 | 观察张望 |
| 😜 调皮 | v0.6新增 | 恶作剧台词 |
| 💕 眷恋 | v0.6新增 | 深情表达 |

### 性格养成四维

| 维度 | 来源 | 累加方式 |
|------|------|----------|
| 话唠值 | 对话 | 每次对话 +1 |
| 粘人值 | 摸头/拥抱 | 每次互动 +1 |
| 学霸值 | 番茄钟 | 每完成 +5 |
| 探险值 | 天气/新技能 | 每次新技能 +3 |

→ 取最高维度形成性格标签 → **注入 system prompt** → GLM 回复风格随之变化

## 十、关键要点总结

| # | 要点 |
|---|------|
| ① | **三进程架构**：主进程管逻辑+数据，渲染进程管画面，预加载桥安全连接 |
| ② | **本地技能优先**：提醒/待办/番茄钟/天气/谜语/环境音走本地秒回，不消耗 token |
| ③ | **GLM 兜底对话**：本地匹配不到才调 Hermes API，离线时降级预设回复 |
| ④ | **12 轮记忆总结**：每 12 条回复触发 GLM 提炼 ≤20 条要点，注入下次对话 |
| ⑤ | **双份持久化**：electron-store（程序用）+ 明文 JSON/MD（用户可读可备份） |
| ⑥ | **12 种情绪 + 四维性格**：情绪影响行为表现，性格影响 GLM 回复风格 |
| ⑦ | **30+ IPC 通道**：渲染进程通过 contextBridge 安全调用主进程服务 |
| ⑧ | **重启不丢**：全部状态持久化，错过的提醒补发，番茄钟跨重启继续 |
| ⑨ | **对接 Hermes**：glm.ts 用 `X-Hermes-Session-Id: desktop-pet` 标识来源 |
| ⑩ | **全局快捷键**：Alt+Y 呼出对话，Alt+J 剪贴板解读（翻译/讲解） |
