## 一、它有多智能？

### 🧠 大脑：GLM-5.2 大模型（可随时更换）
- 所有对话由 OpenAI 兼容接口驱动（默认 `GLM-5.2 @ http://172.22.40.153:8642`），**模型、地址、Key 都能在控制台里热改**，改完立即生效，附"测试连接"按钮
- 接口挂了/没网？自动降级为本地预设回复（带【离线回复】标记），宠物还会闹小情绪——永远不会"死机"

### 📒 长期记忆：越聊越懂你
- 每 12 轮对话自动总结成 ≤20 条记忆要点（称呼、偏好、日程、习惯），**注入到每次对话的上下文**——重启也不忘
- 记忆在你的本地保存**两份**：应用数据库 + 你指定目录下的明文 `记忆.json` / `记忆.md`（随时可读、可备份、可导出导入）

### ⏰ 秘书技能：不止聊天
| 你说 / 你按 | 它做 |
| --- | --- |
| 「提醒我30分钟后站起来」「提醒我明天14:30开会」「半个钟头后叫我喝水」 | 解析中英文数字/相对绝对时间 → 定时 → 到点语音+气泡提醒（重启不错过，错过的补发） |
| 「记一下 明早回邮件」「完成了 回邮件」「待办」 | 本地待办清单：增/完成/查看 |
| 「开个番茄钟」「开个50分钟番茄钟」「番茄钟状态」「停止番茄钟」 | 🍅 番茄钟：专注期间银月安静不打扰；完成时气泡给你三个选择（休息5分钟/再来一轮/结束）；跨重启继续，计入今日统计 |
| 「放点雨声」「来点白噪音」「播些篝火」「停止噪音」 | 程序合成的环境音（雨/篝火/白/粉/棕噪，WebAudio 实时生成，零素材零流量） |
| 「上海天气」「查一下杭州的天气」「今天天气怎么样」 | Open-Meteo 实时天气（免费无 Key）：温度/湿度/风速/降雨概率 + 秘书式穿衣带伞建议；城市自动记忆 |
| 「今日报告」「今日总结」 | 今日工作节律：活跃时长、对话/摸头/番茄钟/提醒确认计数、待办剩余 + 秘书点评 |
| 「出个谜语」「考考我」 | 🧩 谜语问答：32 条内置谜语，答对加经验；银月无聊时也会主动出题（每天最多 2 次） |
| 「写日记」 | 📝 银月日记：聚合今日统计+最近对话，GLM 生成 2-3 句温暖小记，同时写入记忆目录 `日记.md` |
| 「现在几点了」「讲个笑话」「你能做什么」 | 本地秒回（离线可用，零延迟零 token） |
| 「半小时后叫我」（模糊表达） | 本地正则不认识时，自动让 GLM 解析意图再定时 |
| **Alt+Y**（任意应用中） | 全局呼出对话输入框 |
| **Alt+J**（复制内容后） | 剪贴板解读：外文自动翻译成中文，中文/代码/报错自动讲解 |

### 💗 情绪与好感度：一只有脾气的宠物
- **好感度 0–100**：聊天/语音 +2~3、摸头 +1（10s 冷却）、确认提醒 +2、**冷落每 10 分钟 −1**；全部持久化
- **九种情绪**，每种都有不同的"它会干什么"：

| 情绪 | 触发 | 它会做什么 |
| --- | --- | --- |
| 😊 开心 | 好感≥75 / 被摸头 / 积极互动 | 蹦跳幅度大、更爱走动、头顶冒星光、语速轻快、主动分享好心情 |
| 😠 生气 | 接口异常/语音失败/**提醒2分钟不理** | **蹲在原地拒绝走动**、头顶怒气符号、说话变短变冲、语速放缓 |
| 🥺 撒娇 | 好感高时想被关注 | 冒爱心、粘人台词、音调上扬（+15%） |
| 😢 委屈 | 好感<20 / 长期冷落 | 身体趴下、掉眼泪、不爱动、轻声细语 |
| 😲 惊讶 | 提醒突然弹出/定时触发 | 定格+放大弹跳、感叹星光 |
| 😴 困倦 | 23点后空闲 | 打瞌睡动画、冒 Zzz、劝你早点休息 |
| 🤩 兴奋 | 10分钟内互动≥3次且好感≥60 | 小碎步跑得飞快、弹跳翻倍、语速+18% |
| 😑 无聊 | 空闲30分钟以上 | 有气无力、左右张望、主动找你搭话解闷 |
| 🙂 平静 | 默认状态 | 正常待机走动，偶尔换个姿势 |

- **主动搭话**：你长时间不理它，它会按当前情绪主动开口（深夜劝睡、无聊求聊、开心分享）——但每小时最多一两次，不烦人

### 🌱 性格养成：越养越像你（v0.6）
- 四维累计统计（不归零）：**话唠值**（对话）/ **粘人值**（摸头拥抱）/ **学霸值**（番茄钟）/ **探险值**（天气新技能）
- 取最高维度形成性格标签（话唠型/粘人型/学霸型/探险型/均衡型），**注入 system prompt**，GLM 回复风格随之变化；主动搭话间隔也按性格调整
- 控制台「养成」标签实时展示当前性格

### 🏆 成就徽章 + 银月日记（v0.6）
- **12 个成就**：初识/话唠/专注达人/摸摸大师/Lv.3·5·10/连续 7·30 天/首次喂食/全勤日/日记作家——解锁时银月报喜 + 星光粒子
- **银月日记**：每日首次对话/退出/手动触发时自动写今日小记，保留最近 90 天，控制台「系统」标签一键查看

### 🎊 节日彩蛋 + 桌面小卡片（v0.6）
- 元旦/情人节/中秋（农历查表）/圣诞/银月生日/周一早晨：专属问候台词 + 节日粒子
- **桌面小卡片**：气泡旁常驻信息卡，默认显示时间+天气，番茄钟进行时自动切倒计时，有未确认提醒时显示提醒摘要（「助手」标签开关）

### 🖐️ 桌面物理互动（v0.6）
- 拖到屏幕底部边缘 → **坐任务栏**（贴边坐下姿势），坐着时偶尔探头
- 静止超 5 分钟且贴近屏幕左/右边缘 → **半个身位滑出屏外探头探脑**再缩回

### 🔊 声音：三档可调
1. **Edge 神经语音（默认推荐）**：微软神经网络音色（晓伊/晓晓/云希等 8 种预设），免费无需 Key，音质远超系统语音；语速/音调/音量滑杆实时调节，附试听按钮
2. **系统语音（离线）**：Windows 自带中文语音包，完全离线（Edge 不可用时自动降级到它）
3. **自定义克隆端点**：填 OpenAI 兼容 `/v1/audio/speech` 地址即可接入 **GPT-SoVITS / fish-audio / CosyVoice** 等克隆音色服务（见下文"声音克隆指南"）

### 🎮 交互
- 透明置顶窗口、非宠物区域点击穿透，**不影响任何桌面操作**
- 自主走动（不越界）、按住**拖拽**、单击**摸头**
- 工具条：💬 对话 · 🎤 语音 · **🚶/🧍 一键切换走动/静止** · ⚙️ 控制台
- 语音输入：Vosk 中文离线识别（模型 42MB 已预置），说话实时上屏，松开自动发送
- 健康提醒：久坐（默认45分）/ 喝水（默认60分），阈值可改；**2分钟不确认它就生气**

## 三、声音克隆指南（进阶）

真·克隆你自己的声音需要自建或购买 TTS 服务，银月已预留标准接口：

1. 部署任一 OpenAI 兼容语音服务，例如：
   - **GPT-SoVITS**（本地免费，需 N 卡）：`api_server` 起 9880 端口后，兼容 `/v1/audio/speech`
   - **fish-audio / CosyVoice / OpenAI TTS**：拿到 API 地址与 Key
2. 用该服务克隆/上传目标音色，记下 `voice` 名
3. 银月 ⚙️ → 声音 → 引擎选「自定义克隆端点」→ 填端点 URL、模型名、音色名、Key → 试听

不想折腾就用默认 Edge 神经语音，晓伊音色已经是自然的少女声。

## 四、快速开始

```bash
npm install        # Electron 下载失败时：ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm install
npm run dev        # 开发模式（热更新）
npm run preview    # 运行构建产物（日常使用）
npm run selftest   # 无 GUI 自测（13 项：存储/GLM真实调用/TTS合成/定时解析/技能路由/天气…）
npm test           # 61 个单元测试
npm run package    # 打包 Windows 安装包/便携版
```

- 数据与记忆：`%APPDATA%\desktop-pet-yinyue\`；明文记忆副本默认在 `文档\银月记忆\`（可改）
- API Key：`config.local.json`（已 gitignore）或环境变量 `GLM_API_KEY`；也可直接在控制台填写保存
- `F12` DevTools · `Esc` 收起面板 · 托盘双击打开对话

    services/
      appconfig.ts      运行时配置（控制台热改核心）

      todos.ts          待办清单

      store.ts          electron-store 统一持久化（含性格/日记/成就/谜语状态）

  preload/              contextBridge 安全桥（nodeIntegration 关闭）
  renderer/             Canvas 渲染 / 9情绪行为 / 环境音 / 控制台UI（六标签）/ 桌面小卡片 / 探头动画
